Administrator access

The quickest way in is the screen attached to the machine: press P on it and scan the QR code with a phone. That signs this browser in without anything being typed.

The recovery device code below is the other way, and the way back if the screen is not to hand — sixteen characters in four groups, printed on that screen the first time this machine started. Case does not matter and the dashes are optional. Reading this page needs nothing; every button that changes something needs one of the two.

Held for this browser tab only, and never written to disk. Closing the tab locks it again.

Rotating issues a new code and revokes the old one immediately. It also signs out every paired browser, this one included — which is the point, because rotating is what you do when a credential has got out. The new code is shown once, here and on the attached screen, and cannot be asked for again.

    Terminal

    A root shell on the appliance, in the browser.

    This is advanced administration. The shell below runs as root, in the machine's own namespaces, with no confinement — that is deliberate, because a confined shell cannot do the thing anyone opens one for. Everything else in this console is a named operation with a remedy attached; this is the admission that the list of operations cannot be complete, because every fault of the last month was diagnosed by looking at something nobody had thought to expose. ADR-0014: this console is fit for a trusted LAN and is not fit to expose beyond one.
