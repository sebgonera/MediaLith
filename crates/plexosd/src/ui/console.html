    Terminal

    A root shell on the appliance, in the browser.

    This is advanced administration. The shell below runs as root, in the machine's own namespaces, with no confinement — that is deliberate, because a confined shell cannot do the thing anyone opens one for. It is gated by the device token and served over TLS, and ADR-0014 states plainly that this console is fit for a trusted LAN and is not fit to expose beyond one. Everything else in this console is a named operation with a remedy attached; this is the admission that the list of operations cannot be complete.
