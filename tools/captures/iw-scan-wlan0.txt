# Five blocks kept out of fifty-five, one of each kind the parser has to tell apart: WPA2,
# WPA3 (SAE), open, 5 GHz, and one with no SSID line at all -- which is what a hidden
# network looks like from outside.
#
# Only the identifiers were changed -- SSIDs and BSSIDs, because this repository is public
# and the rest of these are the neighbours'. Every other byte is as `iw` printed it,
# including the tabs, the field order, and `freq: 2412.0` with its decimal point, which an
# older `iw` writes without. That is the point of a capture: a fixture somebody imagined is
# a test that agrees with the code and not with the machine.
